BBCode benchmark for tracker descriptions
Paste this whole file into a tracker's description preview (or a private test upload) to see which tags it renders.
Each test has an ID and the expected result. A test fails when the raw tag text shows up or the layout is wrong.
Test labels name tags without brackets so that the label itself is never parsed as BBCode.
Record the failing IDs, then convert or strip those tags for the tracker in DescriptionBuilder.tracker_specific_formats (src/get_desc.py).

==================== 1. TEXT FORMATTING ====================
T01 bold: [b]this text is bold[/b]
T02 italic: [i]this text is italic[/i]
T03 underline: [u]this text is underlined[/u]
T04 strikethrough s: [s]this text is struck through[/s]
T05 strikethrough strike: [strike]this text is struck through[/strike]
T06 superscript: x[sup]2[/sup] (2 raised)
T07 subscript: H[sub]2[/sub]O (2 lowered)
T08 named color: [color=red]this text is red[/color]
T09 hex color: [color=#1E90FF]this text is blue[/color]
T10 short hex color: [color=#0a0]this text is green[/color]
T11 size 1-7 scale: [size=1]size1[/size] [size=2]size2[/size] [size=3]size3[/size] [size=4]size4[/size] [size=5]size5[/size] [size=6]size6[/size] [size=7]size7[/size]
T12 size in pixels (UNIT3D style): [size=10]10px[/size] [size=20]20px[/size] [size=30]30px[/size]
T13 font family: [font=Courier New]this text is monospaced[/font]
T14 nested formatting: [b][i][u][color=orange]bold italic underlined orange[/color][/u][/i][/b]
T15 uppercase tags: [B]bold with uppercase tag[/B]
