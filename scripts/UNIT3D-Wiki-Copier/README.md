# UNIT3D Wiki Copier

Userscript that adds **Copy BBCode** and **Copy Markdown** buttons to the
rendered content of UNIT3D wiki, page, article, and rules pages.

## Installation

1. Install [Tampermonkey](https://www.tampermonkey.net/) or
   [Violentmonkey](https://violentmonkey.github.io/).
2. Open [`UNIT3D-wiki-copier.user.js`](./UNIT3D-wiki-copier.user.js).
3. Copy its contents into a new userscript and save it.
4. Open a compatible UNIT3D wiki, page, article, or rules page.
